# LOCAL-ENV.md — 本机/本环境特有的坑

> **这份文件不跟着模板走。** 它记录的是**你这台机器/这个环境独有**的东西：
> 某个定制 shim、某个虚拟层、某个只在你的沙箱里成立的行为。
> 换机器、换人接手时这些内容会让人困惑，所以它**不进通用教训（GLOBAL-LESSONS.md）**，
> 而是留在本项目里，并明确标注"这是本机特有"。

## 为什么要有这份文件

通用教训与本地环境坑混在一起会互相伤害：

- 本机特有的坑写进通用教训 → 别人照做却发现"我这没这问题"，进而**不信任整份文档**
- 通用教训被本地环境内容冲淡 → 真正该记的跨项目经验被淹没

所以：**跨项目成立 → GLOBAL-LESSONS.md；仅此机器成立 → 这里。**

## 怎么写

每条包含：

| 字段 | 说明 |
|---|---|
| 现象 | 你看到了什么（错误信息 / 异常行为） |
| 环境 | 什么环境触发的（OS、shell、容器、特定版本） |
| 绕过方式 | 实际怎么解决的 |
| 是否可移植 | 换环境后是否还成立；若不成立，说明为什么 |

**判据**：如果你不确定一条经验换台机器还成不成立 —— 它属于这里，不属于 GLOBAL-LESSONS.md。
